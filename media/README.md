# Project Media

This directory contains campaign promotional media, demonstration videos, application screenshots, and marketing materials for the **Campus Anonymous Peer Support Platform**.

## Contents

- **Screenshots**: Screen captures showing student dashboards, anonymous discussion forums, prioritized mentor feeds, and admin analytics panels.
- **Product Demos**: GIF animations and video walk-through links illustrating real-time anonymous chat, emotional urgency logs, and meeting creations.
- **Campaign Posters**: Graphic promotional materials created for first-year student onboarding and campaign awareness.
