# Project Assets

This directory contains static design resources, icons, logos, database schemas, and illustrations for the **Campus Anonymous Peer Support Platform**.

## Contents

- **Vector Graphics**: SVGs and design system vectors (e.g. logos, avatars, emotion indicators).
- **Icons**: Custom or standard icon sets used across the student, mentor, and admin user interfaces.
- **Database Diagrams**: Raw image/vector formats of Entity-Relationship Diagrams (ERDs) and schema models (excluding temporary or compiled artifacts).
