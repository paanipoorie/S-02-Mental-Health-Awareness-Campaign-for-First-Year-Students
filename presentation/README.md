# Presentation

This directory is reserved for project presentations, pitch decks, slides, and demonstration materials regarding the **Campus Anonymous Peer Support Platform**.

## Contents
- **Slides**: PDF or PPTX slide decks detailing the project objectives, architecture, features, and outcomes.
- **Pitch Deck**: High-level presentation summarizing the mental health campaign and platform details.
- **Demonstration Materials**: Visual aids used during evaluation and project showcases.
